# サイト更新アプリ（スマホ用）

事務ご担当者様が、スマホからお知らせと施工事例を入れるための画面です。
写真を撮るか選ぶだけで使えます。ドライブのリンクを貼る作業は要りません。

```
スマホの画面 ──保存──▶ 共有フォルダに写真を置く（リンクを知っている全員が閲覧可）
                └──▶ 台帳（スプレッドシート）に1行書く
                         │
                         ▼  今までどおり10分おきの自動反映
               .github/workflows/news-from-sheet.yml ──▶ サイト
```

- お知らせは台帳の**2行目**に差し込みます。台帳の上から順にサイトに並ぶためです。
- 施工事例は空いている行に書きます。並び順は「表示順」の数で決まります（先頭に出す＝今の最小−1、最後に出す＝今の最大＋1）。
- 施主様の承諾にチェックがない施工事例は、公開できません。
- 「登録済み」タブでは、公開と非公開を切り替えられます。文章の手直しは、今までどおり台帳で行います。

## ファイル

| ファイル | 中身 |
|---|---|
| `Code.gs` | サーバー側の処理（台帳への書き込み・写真の保存） |
| `index.html` | スマホの画面 |
| `appsscript.json` | 設定（会社のアカウントだけが使える／使う人の権限で動く） |
| `tests/` | 動作確認用（Apps Scriptには入れません） |

## 最初に1回だけ行う設置（管理する方）

1. https://script.google.com で「新しいプロジェクト」を作り、名前を「サイト更新」にします。
2. 左の歯車（プロジェクトの設定）を開き、「appsscript.json マニフェスト ファイルをエディタで表示する」にチェックを入れます。
3. エディタで `Code.gs`・`appsscript.json` の中身を、このフォルダのものに置き換えます。
   ＋ボタンから HTML ファイル `index` を作り、`index.html` の中身を貼ります。
4. プロジェクトの設定 → **スクリプト プロパティ** に、次の値を登録します。

   | プロパティ | 値 |
   |---|---|
   | `NEWS_SHEET_ID` | お知らせ台帳のURLの `/spreadsheets/d/` と `/edit` の間の文字 |
   | `NEWS_SHEET_NAME` | （任意）シート名。空なら列名から自動で探します |
   | `CASES_SHEET_ID` | 施工事例台帳のID（空なら施工事例タブは使えません） |
   | `CASES_SHEET_NAME` | （任意）シート名 |
   | `PHOTO_FOLDER_ID` | 写真を置く共有フォルダのURLの `/folders/` の後ろの文字 |

5. エディタ上部の関数から `設定を確認する` を選んで「実行」します。初回は権限の許可を求められます。
   実行ログがすべて「OK」になれば準備完了です。
6. 「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」で、次のように設定してデプロイします。
   - 次のユーザーとして実行：**ウェブアプリにアクセスしているユーザー**
   - アクセスできるユーザー：**（会社のドメイン）内の全員**
7. 表示されたURL（`/exec` で終わるもの）を、事務ご担当者様に渡します。

### 使う人に必要な権限

このアプリは「使う人の権限で」動きます。誰が何を書いたかが、台帳とドライブの履歴に残ります。
そのため、使う人には次の権限が要ります。

- お知らせ台帳・施工事例台帳の**編集権限**
- 写真の共有フォルダの**編集権限**

## 事務ご担当者様の使い方

1. 渡されたURLをスマホで開きます。初回だけ、Googleの許可画面が出ます。
2. ホーム画面に置いておくと、アプリのように開けます。
   - iPhone（Safari）：共有ボタン →「ホーム画面に追加」
   - Android（Chrome）：︙ メニュー →「ホーム画面に追加」
3. 入力して［保存する］を押します。10分ほどでサイトに出ます。

## うまくいかないとき

| 画面の文言 | 原因と対処 |
|---|---|
| 「リンクを知っている全員が閲覧可」にできませんでした | Google Workspaceの管理者設定で、外部への共有が止められています。自動反映はログインせずに写真を取りに行くため、この共有が必要です。 |
| 台帳を開けませんでした／共有フォルダを開けませんでした | 使っている人に編集権限がありません。 |
| 台帳の行が動いていたため、書き換えを止めました | 画面を開いたあとに、台帳の行が増減しました。画面を読み込み直してください。 |
| 必要な列がありません | 台帳の1行目の見出しが変わっています。列名は `tools/お知らせ台帳_生成.py`・`tools/施工事例台帳_生成.py` と同じにしてください。 |

## Code.gs・index.html を直したとき

```
node apps/更新アプリ/tests/server.test.js   # 偽の台帳で書き込みを確認
node apps/更新アプリ/tests/ui.test.js       # スマホの画面を確認（Playwright）
```

確認できたら、Apps Scriptのエディタに貼り直します。
そのあと「デプロイを管理」→ 鉛筆マーク →「バージョン：新しいバージョン」で更新します。
URLは変わりません。
